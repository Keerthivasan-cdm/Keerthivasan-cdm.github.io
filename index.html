    Medical Device

Keerthivasan JProject 05

  

    
SMART BIN

    Waste Segregation
  

  

    

      
Team Project · Arduino + Raspberry Pi · Aug 2025

      
An automatic waste-segregation bin that separates biodegradable and non-biodegradable waste. A Raspberry Pi identifies the waste and sends the result over UART; the Arduino opens the right lid with a servo, confirms the drop with an ultrasonic sensor, and shows prompts and reward messages on a P10 LED matrix.

      
    
        
  • Serial protocol: user name → greeting, 0 → bio lid, 1 → non-bio lid
    • 
        
  • Two servos (0 → 115°) and two HC-SR04 sensors keep each lid open until the path is clear (> 30 cm)
    • 
        
  • Scrolling P10 display driven over SPI with DMD2
    •
